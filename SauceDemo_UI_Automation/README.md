# QA Internship Project

This repository contains QA testing activities completed as part of my internship project, covering web UI testing, API testing, and performance testing.

## Projects and Testing Activities

| Application | Testing Type | Tools |
|---|---|---|
| SauceDemo | Manual UI Testing | Google Chrome |
| SauceDemo | UI Automation | Playwright, TypeScript |
| ReqRes | API Testing | Postman |
| ReqRes | Performance Testing | Apache JMeter |

## 1. SauceDemo – UI Testing

Application: https://www.saucedemo.com/

Testing activities:
- Test planning and documentation
- Test scenarios and test cases
- Requirement Traceability Matrix (RTM)
- Manual test execution
- Defect identification and reporting
- Playwright UI automation using the Page Object Model

Documentation and automation reports are available in the SauceDemo folders.

## 2. ReqRes – API Testing

Application: https://reqres.in/

Testing activities:
- API test scenarios
- Positive and negative API testing
- CRUD operations using Postman
- Status code and response validation
- Postman collection and environment

## 3. ReqRes – Performance Testing

Performance testing was conducted using Apache JMeter.

Project deliverables include:
- JMeter test plan
- Execution results
- Performance test report

## Tools and Technologies

- Playwright
- TypeScript
- Postman
- Apache JMeter
- Git and GitHub
- Microsoft Excel and Word

## Important Note

API and performance testing were conducted separately against ReqRes. They were not performed against the SauceDemo application.

## Repository Structure

The repository is organized into separate sections for SauceDemo UI automation, SauceDemo documentation, ReqRes API testing, and ReqRes performance testing.

Please refer to the individual project folders for test scripts, reports, collections, and supporting evidence.
