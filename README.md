## Project Overview

This repository contains testing documentation, test cases, automation scripts, execution reports, and supporting evidence for the following projects.

### 1. SauceDemo – Manual Testing

**Application:** [SauceDemo](https://www.saucedemo.com/)

- Test plan and test scenarios
- Test cases and Requirements Traceability Matrix (RTM)
- Manual test execution report
- Bug reports and supporting evidence

**Execution Result:** 31 test cases passed.

### 2. SauceDemo – UI Automation

**Application:** [SauceDemo](https://www.saucedemo.com/)

- Playwright with TypeScript
- Page Object Model (POM)
- Automated login, product, cart, and checkout tests
- HTML test execution report

**Execution Result:** 24 automated tests across Chromium, Firefox, and WebKit, resulting in 72 executions.

### 3. ReqRes – API Testing

**API Platform:** [ReqRes](https://reqres.in/)

- API testing using Postman
- Positive and negative test scenarios
- CRUD operation testing
- Authentication and error-case testing
- API execution report and supporting evidence

### 4. ReqRes – Performance Testing

**API Platform:** [ReqRes](https://reqres.in/)

- Performance testing using Apache JMeter
- JMeter test plan
- Performance test report
- Execution results and supporting evidence
